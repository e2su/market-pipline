// About this page

How it works

  • Your browser connects to Binance's public market-data stream directly. There's no server and no API key.
  • Trades are grouped into 30-second batches. Each trade is compared with the previous batch's median price.
  • History lives only in this tab: reload it and the chart starts from the last 30 one-minute candles again.

What the full pipeline adds

  • Stock quotes (the API key can't be put in a public web page).
  • Permanent history in S3 and the warehouse.
  • Exactly-once processing with checkpoints, and automatic restarts on the server.
